SPACE VAULT: ESCAPE FROM EARTH
README - HOW TO RUN THE GODOT PROJECT
=====================================

This README explains how to run the game's original Godot project if the Windows .exe does not work.

REQUIREMENTS
------------
- Windows PC (or another system supported by Godot)
- Godot Engine 4.7.2 (use the same version as the project where possible)
- The COMPLETE project folder, not just the .exe

HOW TO OPEN AND PLAY
--------------------
1. Download and install Godot Engine from https://godotengine.org/download/.
2. Extract the supplied SPACE VAULT project ZIP to a normal folder, if it is zipped.
3. Check that the extracted project contains a file named project.godot.
4. Open Godot Project Manager.
5. Click Import, browse to the SPACE VAULT folder and select project.godot.
6. Click Import & Edit (or Edit) to open the project.
7. Allow Godot to finish scanning/importing assets and scripts.
8. Press F5 or click the Play Project button in the top-right corner.
9. When the Main Menu appears, click CLICK TO START to begin the game.

EXPECTED GAME FLOW
------------------
Main Menu -> Introduction -> Lab Infiltration -> Outside Lab ->
Four Scientist battles (Dr. Niq, Dr. Gabby, Dr. Ahmed, Dr. Celine) ->
Workbench/spacecraft upgrades -> Rocket Launch -> Mission Debrief ->
View Ending -> Main Menu.

IF F5 DOES NOT OPEN THE MAIN MENU
--------------------------------
1. In Godot, open Project > Project Settings > Application > Run.
2. Set Main Scene to:
   res://Main menu/node_2d.tscn
3. Close Project Settings and press F5 again.

TROUBLESHOOTING
---------------
- "Project not found": Select the project.godot file, not an individual scene.
- Missing scenes, scripts or images: Make sure you extracted and shared the ENTIRE project folder, including assets, data, dialogue/dialogues, scenes, scripts, and Main menu.
- Parse errors: Confirm you are using the project's matching Godot version, and check the Errors/Output panel for the exact file and line number.
- Black screen or frozen scene: Stop the game, reopen the project, let the asset import finish, and try F5 again. Check the Godot Debugger and Output panels.
- F5 reports missing Main Scene: Follow the Main Scene steps above.
- Game progresses incorrectly: Check that all project files were included and that none were renamed or moved.
- Export templates missing: They are needed to create an .exe, but NOT to run the game inside the Godot editor.

IMPORTANT FOR SHARING
---------------------
Send the COMPLETE project as a ZIP. Do not send only project.godot, a single .tscn, or the Windows .exe. Keep existing folder names and capitalization, including the space in "Main menu". The .godot folder can usually be regenerated by Godot when the project is first opened.

GAME NOTES
----------
SPACE VAULT is a pixel-art game about Joe Peng escaping Earth. Defeat the four Scientists, collect spacecraft upgrades, and complete the final mission.

If the game does not start, send the developer a screenshot of Godot's first red error in the Debugger/Output panel along with the Godot version being used.
